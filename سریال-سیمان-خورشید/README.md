## خلاصهٔ قسمت‌ها

1. **دود و صبح** — معضل آلودگی، جرقهٔ ایده، معرفی استارتاپ.
2. **سیمان خورشید** — اثبات علمی فناوری با استاد، خبر جلسه با سرمایه‌گذار.
3. **جلسه** — ارائه به مقتدری؛ تردید و پیشنهاد تست میدانی.
4. **تست خیابان** — داده‌های واقعی در خیابان تهران؛ سرمایه‌گذار قانع می‌شود.
5. **قرارداد** — مذاکرهٔ نهایی، امضا و پایان فصل.

## پیشنهاد نحوهٔ ساخت ویدیو (در نرم‌افزار تدوین مثل Premiere / CapCut)

- **قسمت ۱:** تصویر «صبح-دود» به‌عنوان پس‌زمینه + نریشن قسمت ۱. روی تصویر، تیتر «سیمان خورشید — قسمت اول» را بگذارید.
- **قسمت ۲:** تصویر «آزمایشگاه» + نریشن قسمت ۲.
- **قسمت ۳:** تصویر «جلسه» + نریشن قسمت ۳.
- **قسمت ۴:** تصویر «تست-خیابان» + نریشن قسمت ۴.
- **قسمت ۵:** تصویر «قرارداد» + نریشن قسمت ۵، و زیرنویس پایانی «پایان فصل اول — ادامه دارد».

برای هر قسمت می‌توانید از دیالوگ‌های داخل سناریو، زیرنویس فارسی اضافه کنید و بین صحنه‌ها کمی زوم/پن (حرکت کمایرا) و افکت عبور نور برای حس سینمایی بگذارید.

## اطلاعات فنی بتن فتوکاتالیست (برای صحت محتوا)

- فناوری بر پایهٔ **دی‌اکسید تیتانیوم (TiO2)** است که با نور فرابنفش، آلاینده‌ها (NOx، SOx، VOC) را به نیترات، آب و CO2 تبدیل می‌کند.
- دارای خاصیت **خودتمیزکنندگی** و کاهش ~۴۵٪ NOx در کاربرد مناسب.
- از فناوری‌های واقعی و فعال در ژاپن و اروپاست.
