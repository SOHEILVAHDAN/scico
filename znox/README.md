# Z-NOX — انیمیشن ارائهٔ طرح کسب‌وکار + ویدیو

انیمیشن حرفه‌ای و خودکار (تصویری + روایت صوتی فارسی) برای ارائهٔ طرح **Z-NOX — بتن فتوکاتالیست دوپ‌شده با کربن فعال** در رویداد بذر طلایی، مرداد ۱۴۰۵.

| مسیر | توضیح |

## اجرا

ساده‌ترین راه: فایل `Z-NOX-Animation.html` را در مرورگر باز کنید (فولدر `audio` باید کنارش باشد) و دکمهٔ **«شروع ارائه با صدا»** را بزنید.

یا اجرای سرور محلی:

```bash
cd znox
python3 -m http.server 8000
# سپس http://localhost:8000/Z-NOX-Animation.html
```
