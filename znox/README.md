# Z-NOX — انیمیشن ارائهٔ طرح کسب‌وکار

انیمیشن حرفه‌ای و خودکار (تصویری + روایت صوتی فارسی) برای ارائهٔ طرح **Z-NOX — بتن فتوکاتالیست دوپ‌شده با کربن فعال** در رویداد بذر طلایی، مرداد ۱۴۰۵.

## فایل‌ها

| مسیر | توضیح |
|---|---|
| `Z-NOX-Animation.html` | **خروجی نهایی** — تک‌فایلِ کاملاً خودکفا (فونت Vazirmatn + روایت صوتی داخل فایل embed شده)؛ کافی است فقط همین یک فایل را دانلود کنید و در مرورگر باز کنید |
| `audio/` | فایل‌های روایت صوتی هر صحنه (`seg01.mp3` تا `seg18.mp3`) |
| `src/` | کد منبع (CSS، HTML صحنه‌ها، JS موتور پخش) |
| `build.py` | اسکریپت ساخت: `python3 build.py` — خروجی تک‌فایل را با فونت و صداهای embed بازتولید می‌کند |
| `server.py` | سرور محلی با مسیر دانلود: `python3 server.py` → `http://localhost:8420/download` |

## اجرا

ساده‌ترین راه: فایل `Z-NOX-Animation.html` را در مرورگر باز کنید (فولدر `audio` باید کنارش باشد) و دکمهٔ **«شروع ارائه با صدا»** را بزنید.

یا اجرای سرور محلی:

```bash
cd znox
python3 -m http.server 8000
# سپس http://localhost:8000/Z-NOX-Animation.html
```

## شخصی‌سازی روایت

متن هر صحنه در `src/scenes.html` و تایمینگ صداها به‌صورت خودکار از طول فایل‌های `audio/*.mp3` محاسبه می‌شود؛ برای تغییر صدا، فایل صوتی را عوض کنید (هم‌نام) یا `src/app.js` را ویرایش کنید.
