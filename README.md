# خانه شماره ۶ — استودیو سَهی، شیراز

> روایتی سینمایی از یک خانه؛ شش فصل، شش ایده.

## درباره پروژه

این وبسایت پورتفولیوی طراحی داخلی «خانه شماره ۶» است — پروژه‌ای از استودیو سَهی در شیراز.

### شش فصل

| فصل | عنوان | ایده |
|------|--------|------|
| ۰۱ | آستانه | نور را نبند، ترجمه‌اش کن |
| ۰۲ | اتاق تاریک روشن | تاریکی زمینه است، روشنی اتفاق |
| ۰۳ | نور بی‌منبع | چراغ را پنهان کن، سطح را روشن کن |
| ۰۴ | طاقچه‌های منحنی | تزیین را حذف کن، جایش حفره بساز |
| ۰۵ | سنگِ آب | جزئیاتی که دست می‌فهمد، نه دوربین |
| ۰۶ | سبز، بیرون از قاب | آخرین متریالِ خانه، باغ است |

### پالت متریال

- 🟫 چوب گردوی دودی
- 🟨 حصیر بافت وین
- ⬜ تراورتن روشن
- ⬜ کتان طبیعی
- 🟡 برنج مات
- 🟢 سبز باغ

### سبک

**مینیمالِ گرمِ شرقی** — هندسه آرام، ماده به‌جای رنگ، نورپردازی لایه‌ای در ۲۷۰۰ کلوین.
