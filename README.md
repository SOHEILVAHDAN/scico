# Zinax — Sohi Studio

Persian, RTL cinematic architectural portfolio. Open `index.html` directly, or serve with:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

No build dependencies. The optional Google font falls back to local Tahoma. Upload project photos using the bottom toolbar, then save a self-contained HTML with embedded, resized JPEG images. Images are processed locally and not uploaded. Print/PDF uses the browser print dialog.

The original image files were not accessible in this workspace. Initial photo areas are explicitly labeled placeholders, not substitute project imagery. The opening visual is an abstract CSS composition.

Plans, section and connection details are conceptual studies, not measured project drawings or construction documents. Project information supplied by the user: Zinax trading company, design by Sohi Studio, inspiration from a future involving clean-air reactors and innovative materials.
