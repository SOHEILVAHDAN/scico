# SCICO — پورتفولیو پرینتر سه‌بعدی بتن و سفال

پورتفولیوی تک‌فایل HTML برای «سیکو ۰۱» — پرینتر سه‌بعدی بزرگ‌مقیاس بتن و سفال، با ساختار سینمایی اسکرول‌محور (Acts) الهام‌گرفته از oryzo.ai.

## اجرا
```bash
python3 -m http.server 8000   # سپس http://localhost:8000
```
هیچ وابستگی بیرونی نیست — GSAP و Three.js به‌صورت محلی در `vendor/` قرار دارند.

## ساختار
- **ACT 01 — STRUCTURE**: انفجار/مونتاژ قطعات پرینتر در صحنه‌ی سه‌بعدی (اسکلت، پرتال، سر چاپ، تغذیه)
- **ACT 02 — MATERIAL**: چاپ واقعی مسیر ابزار — دیوار بتن (۴۴ لایه) و سپس کوزه‌ی سفالی (۳۴ حلقه)؛ گانتری همیشه نازل را دنبال می‌کند
- **ACT 03 — VOLUME**: جعبه‌ی حجم چاپ ۴٫۰×۲٫۵×۲٫۲ متر (۲۲m³) + ماشین‌حساب لایه تعاملی
- مشخصات فنی، گالری افقی پروژه‌ها، شمارنده‌ها و CTA

## فایل‌ها
- `index.html` — همه‌چیز (CSS/JS داخل فایل)
- `assets/p1..p6.jpg` — تصاویر پروژه‌ها
- `vendor/` — gsap 3.12.5، ScrollTrigger، three r128 (MIT)
