# Z-NOX — کاتالوگ ویدیویی و برند

کاتالوگ موشن‌ویدئویی **زیناکس (Z-NOX)** برای معماران، به‌همراه نشان برند و موشن‌لوگو.

> زیناکس یک **پوشش فتوکاتالیستی** است که روی **پنل سرامیکی بتنی** دوپ‌شده با **کربن اکتیو** اجرا می‌شود؛ با **نور مرئی** فعال می‌شود، **CO₂** را جذب و **اکسیژن** آزاد می‌کند.

- `index.html` — پخش‌کنندهٔ تعاملی (۹ فصل، نریشن فارسی، نوار فصل). `?mode=logo` برای موشن‌لوگو.
- `catalog.html` — کاتالوگ آنلاین اسکرولی؛ اسکرول = تایم‌لاین فیلم.
- `out/ZNOX-Catalogue-1080p.mp4` — فیلم کامل ۱۹۲۰×۱۰۸۰ با صدا (۲:۲۴)
- `out/znox-logo-sound.mp4` — موشن‌لوگوی ۵٫۶ ثانیه‌ای با صدا
- `assets/logo/` — نشان و لوک‌آپ به‌صورت SVG و PNG
- `BRAND.md` — راهنمای برند، پالت، تایم‌لاین و مشخصات فنی
- `DOWNLOAD.md` — فهرست لینک‌های دانلود

```bash
npm run serve     # http://localhost:4173
npm run audio     # ساخت نریشن + پس‌زمینه
npm run render    # فیلم
npm run logo      # موشن‌لوگو
```
